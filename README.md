# CrossOver Trial Reset Script

Rather simple concept. I can't afford to pay for CrossOver and I bet there are others who can't afford/won't pay for it either. A while ago, I found that I could just simply reset the trial date manually. I have now automated this with one script. 

# Usage

1. Download the reset_crossover.sh file from the latest [release](https://github.com/ValiantWind/CrossOver-Trial-Reset/releases)
2. Open Terminal
3. Type the following snippet below (ensure there is a space after the x) and then drag and drop the downloaded script from the finder into Terminal so the path to the file autofills. 
    ```sh
    chmod +x 
    ```
    This will make the script executable.
4. Run the script. All you need to do is drag and drop and press enter:
   ```sh
    path/to/reset_crossover.sh
   ```

## BONUS:

If you want to make it so you can just double click the file to run it, you just need to change the file extension from ".sh" to ".command" and THEN follow the instructions above.
