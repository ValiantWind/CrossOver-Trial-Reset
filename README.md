# CrossOver Trial Reset Script

Rather simple concept. I don't wanna pay for CrossOver and I bet most others don't want to either. A while ago I found that I could just simply reset the trial date manually. I have now automated this with one script.

# Usage

1. Download the reset_crossover.sh file to your Downloads Folder
2. Open Terminal
3. Type this command to give it permission to execute: 
    ```sh
    chmod +x ~/Downloads/reset_crossover.sh
    ```
4. Run the script:
   ```sh
   ~/Downloads/reset_crossover.sh
   ```
